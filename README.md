# 🏏 PyCricket Analytics

A Python-based data visualization project that analyzes cricket match data (Pakistan vs USA) using powerful libraries like pandas, matplotlib, and seaborn.


## 📊 Features

- Visualize runs per over using bar charts
- Compare performance of Pakistan and USA
- Display values on graphs for better understanding
- Read real match data from CSV file
- Clean and simple data visualization


## Technologies Used

- Python 
- Pandas
- Matplotlib
- Seaborn
